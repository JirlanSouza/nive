# Architecture Decision Records

Architecture Decision Records capture important technical decisions, the context behind them, and their consequences.

Use ADRs for decisions that affect long-term architecture, cross-crate boundaries, storage formats, workflows, or compatibility.

## Index

- `0001-active-rust-iced-stack.md`: active desktop stack and legacy UI boundaries.
- `0002-global-db-and-project-db.md`: global/project database split and isolation rules.
- `0003-docling-rkyv-payload.md`: canonical parsed artifact format.
- `0004-python-parser-process.md`: isolated parser process and protocol boundary.
